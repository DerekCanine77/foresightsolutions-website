Ontology and workflow

Foundry Ontology design connected to how work actually moves.

Foresight advises on the Ontology a decision depends on: which object types should stay stable, which Actions a person may take, and how a Workshop application should present the work. This is design guidance for teams that already run Foundry.

Object types

Advise on the Ontology object types and links that should stay stable across applications, plants, regions, and functions.

Actions

Advise on the Actions a user needs to take, not only the objects they need to inspect.

Workshop fit

Map how a decision moves so a Workshop view would support the operating cadence instead of sitting beside it.

Reuse in the Ontology

Advise on patterns that make the next use case easier to define than the last.

Who uses it

Design guidance for the people who approve, coordinate, and close the work.

Who can change it

Clarify who may change object types, release a Workshop change, and retire a fragile workaround.

Practical outcome

Make the Ontology match how the work moves.
