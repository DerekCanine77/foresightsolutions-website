# Foresight Solutions website

Static site for [foresightsolutions.io](https://foresightsolutions.io/). Upload the files listed in `README_DEPLOYMENT.md` to GoDaddy `public_html`. The server does not run a build.

Internal notes live in `docs/` and are not part of the public site. Shared header, footer, and social tags are regenerated locally with `python3 scripts/sync-chrome.py`.
